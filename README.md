# projects

Source for [projects.beeliever.net](https://projects.beeliever.net), the Beeliever project hub: case studies and playable builds.

A single static page, no build step. `index.html` is the whole site.

Deployed by Cloudflare Pages from this repo. Pushes to the principal branch deploy automatically.

Lead project: [Salvage Bots](https://autofire.beeliever.net), a playable browser game, live and installable as a PWA.
